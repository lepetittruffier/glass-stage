4 · Claude Code~/.claude/settings.json + themes/epoq.json
dark-ansi defers to the terminal palette (standard). The epoq theme pins the pulse green + forces non-red diffs. 
// ~/.claude/settings.json — the standard: follow the terminal palette
"theme": "dark-ansi"

// ~/.claude/themes/epoq.json — OPTIONAL: pin exact epoq inks
//   (then set  "theme": "custom:epoq"  in settings.json)
{
  "name": "epoq",
  "base": "dark-ansi",
  "overrides": {
    "claude":          "#2CFF05",   // the thinking pulse (--signal-live)
    "success":         "#2CFF05",
    "error":           "#8E00FF",   // the no-red flag (--signal-go)
    "warning":         "#6F75D7",
    "promptBorder":    "#5F5295",
    "diffAdded":       "#12301A",
    "diffAddedWord":   "#1F5A2E",
    "diffRemoved":     "#1A0330",   // no red — a dark --signal-go tint
    "diffRemovedWord": "#5C1A9E"
  }
}

law 01Characters, not photographs
        A photo hides distortion. A monospace grid measures it. The bend is legible because the thing behind the glass is a ruler.

      
law 02Lit from inside
        Apple's glass is lit by its environment. This one is lit by its contents — the characters are the phosphor, and the light leaves the tile.

      
law 03Black glass
        The pane is dark. The specular rim is the only white on it.

      
law 04The prism obeys the palette
        Ordinary aberration splits into red, green, blue. This one splits into inks you name — and the default set contains no red. Epoq legislates none, down to the physics.

    


    

      
Take itglassci/glassci.css + glassci.js — MIT, zero dependencies

        Two files. No WebGL, no canvas, no build step. Every ink reads through var(), so it inherits an epoq page and still works anywhere else.
        

      
<link rel="stylesheet" href="glassci/glassci.css">
<script src="glassci/glassci.js"></script>

<div class="glassci" data-glassci
     data-glassci-radius="0.26"
     data-glassci-depth="18"
     data-glassci-strength="24"
     data-glassci-dispersion="3">
  <pre class="glassci-lit">the record, drawn in characters</pre>
</div>
