3 · git — no-red diffs~/.gitconfig · runs once
Deletions magenta, additions green, hunks hum-blue, meta dim. Kills red in diff + status + log. 
git config --global color.ui auto
git config --global color.diff.meta       "#515151"
git config --global color.diff.frag       "#6F75D7 bold"
git config --global color.diff.func       "#5F5295"
git config --global color.diff.commit     "#6F75D7"
git config --global color.diff.old        "#B657C9"   # deletions — NOT red
git config --global color.diff.new        "#59C24E"   # additions
git config --global color.diff.whitespace "reverse #D805FF"
git config --global color.status.added     "#59C24E"
git config --global color.status.changed   "#6F75D7"
git config --global color.status.untracked "#515151"
git config --global color.status.deleted   "#B657C9"
git config --global color.status.branch    "#2CFF05"
git config --global color.decorate.branch       "#2CFF05"
git config --global color.decorate.remoteBranch "#6F75D7"
git config --global color.decorate.HEAD         "#D805FF"
git config --global color.decorate.tag          "#5F5295"
4 · Claude Code~/.claude/settings.json + themes/epoq.json
dark-ansi defers to the terminal palette (standard). The epoq theme pins the pulse green + forces non-red diffs. 
// ~/.claude/settings.json — the standard: follow the terminal palette
"theme": "dark-ansi"

// ~/.claude/themes/epoq.json — OPTIONAL: pin exact epoq inks
//   (then set  "theme": "custom:epoq"  in settings.json)
{
  "name": "epoq",
  "base": "dark-ansi",
  "overrides": {
    "claude":          "#2CFF05",   // the thinking pulse
    "claudeShimmer":   "#1A8F00",
    "success":         "#2CFF05",
    "error":           "#D805FF",
    "warning":         "#6F75D7",
    "promptBorder":    "#5F5295",
    "diffAdded":       "#12301A",
    "diffAddedWord":   "#1F5A2E",
    "diffRemoved":     "#2A1230",   // no red
    "diffRemovedWord": "#7A2E8A"
  }
}

    done-when: Vercel build succeeds on push to main.
  3. ~2 minShip it. Confirm the deploy, hit the URL, verify the terminal + palette render in Red Hat Mono on a cold load.
    done-when: glass-stage.vercel.app is LIVE — the real condition, not "worked on".

    done-when: a section renders on epoq3.vercel.app.
